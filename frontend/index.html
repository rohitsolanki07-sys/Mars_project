    DATA & SOFTWARE CREDITS

    Mars Navigator uses public Mars mapping and science resources. Source data remains the property of its providers; their use does not imply endorsement.

    NASA / JPL Mars Trek

    13 live map/data service layers plus 1 site-image preview are integrated from NASA/JPL Mars Trek. These are data sources, not 14 NASA software tools.

    • Viking MDIM 2.1 global color mosaic
    • MOLA/HRSC color-shaded relief
    • MOLA/HRSC elevation data
    • Curiosity HiRISE mosaic, traverse, and waypoints
    • InSight CTX mosaic
    • Perseverance traverse, named locations, and landing ellipse
    • Official Mars nomenclature, major surface features, and named regions
    • Jezero Crater site-image preview (the additional image asset)

    USGS Astrogeology

    Approved planetary names may link to the USGS Gazetteer of Planetary Nomenclature, which is a reference for individual named features.

    Software used

    • CesiumJS — interactive 3D Mars globe
    • Express — local API and web server
    • Node.js — application runtime

    NASA, JPL, USGS, and other listed providers do not endorse this project. The route planner is experimental and not certified for mission use.

    ABOUT NEUROMARS

    NeuroMars is building a Mars surface navigation prototype to explore map-based route planning, terrain awareness, and mission information in one place.

    Important limitation

    This project is a research and demonstration aid, not an operational navigation system. Its terrain data cannot reveal small rocks, cracks, dust conditions, or current surface hazards. Astronauts must rely on validated mission systems and human review.
